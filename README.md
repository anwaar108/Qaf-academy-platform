# 📌 QAF Academy Learning Platform

A full-stack educational platform designed to manage courses, lessons, and student engagement using ASP.NET Web Forms and SQL Server.

---

## 🚀 Features
- Course management system  
- Student enrollment system  
- Lesson organization  
- Admin control panel  
- User-friendly interface  
- Structured database integration  

---

## 🛠 Tech Stack
- ASP.NET Web Forms  
- SQL Server  
- HTML  
- CSS  
- JavaScript  
- C#  

---

## 🎯 Project Goal
This project simulates a real-world educational platform with structured backend logic, database integration, and a user-friendly interface designed to improve learning management efficiency.
