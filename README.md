# 📌 Qaf-academy-platform

A full-stack educational platform designed to manage courses, lessons, and student engagement using ASP.NET and SQL Server.

🚀 Features
Course management system
Student enrollment system
Lesson organization
Admin control panel
🛠 Tech Stack
ASP.NET Web Forms
SQL Server
HTML, CSS, JavaScript
🎯 Project Goal

To simulate a real-world educational platform with structured backend logic, database integration, and user-friendly interface.
